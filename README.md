# Ayisha Network Scan 🔍

## 🔐 Cybersecurity Project
This project demonstrates basic network reconnaissance techniques used in cybersecurity and IT security monitoring.

## 📌 Overview
A Python-based network scanning tool that detects active hosts and open ports to identify basic network exposure risks.

## ⚙️ Features
- Detects live hosts on a network  
- Identifies active IP addresses  
- Basic port scanning capability  

## 🛠️ Tools Used
- Python  
- python-nmap  
- Nmap  

## 🎯 Purpose
Built for cybersecurity learning and to demonstrate foundational skills in network analysis and ethical hacking.
